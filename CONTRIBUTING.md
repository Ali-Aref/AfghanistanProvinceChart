# Contributing

Thank you for your interest in improving Afghanistan Province Charts! Bug reports,
accessibility improvements, documentation fixes, and sourced corrections to
province names are welcome.

Please read the [contributing guide](./docs/contributing.md) for setup instructions,
development commands, testing expectations, and the pull request checklist.
Changes to geographic data also require following the
[data and licensing guide](./docs/data-and-licensing.md); please do not replace
the boundary dataset without updating its provenance and attribution.
