# ژبنیز ملاتړ

| د `locale` ارزښت | ژبه                    | لوری     | د `Intl` بڼه |
| ---------------- | ---------------------- | -------- | ------------ |
| `en`             | انګلیسي                | چپ-نه-ښي | `en-US`      |
| `prs`            | دري (افغانستاني فارسي) | ښي-نه-چپ | `fa-AF`      |
| `ps`             | پښتو                   | ښي-نه-چپ | `ps-AF`      |

`prs` د بستې په API کې د دري کوډ دی؛ له `fa` یا د ایران له فارسي (`fa-IR`) سره یې بې له ځانګړې پرېکړې مه بدلوئ. اصلي ژبه انګلیسي ده. د ټولو ۳۴ ولایتونو نومونه، څرګندونې، رنګیز لارښود، د لاسرسي نومونه او شمېرې د `locale` په بدلولو بدلېږي.

```tsx
<AfghanistanMap locale="prs" />
<AfghanistanChoropleth locale="ps" data={data} showLegend />
```

د `AF-KAB` په څېر ISO کوډونه په ټولو ژبو کې یو شان پاتې کېږي. ښي-نه-چپ بڼه یوازې د متن او رنګیز لارښود لپاره ده؛ **د نقشې هندسه او جغرافیایي لوری نه بدلېږي**. د `legendTitle` ځانګړی سرلیک او د `renderTooltip` ځانګړې منځپانګه کاروونکی پخپله ژباړي. که ټوله پاڼه ژباړل کېږي، د سند `lang` او `dir` هم وټاکئ.

د دري او پښتو نومونه د فارسي او پښتو ویکیپېډیا له نوملړونو سره کتل شوي دي (ترلاسه شوي ۲۰۲۶-۱۱-۲۳). سیمه‌ییزې لیکنې توپیر لري؛ د سمونې لپاره باوري سرچینه وړاندې کړئ. [بشپړ انګلیسي لارښود](../localization.md) هم وګورئ.
