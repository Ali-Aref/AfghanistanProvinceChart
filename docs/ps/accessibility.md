# لاسرسی

متقابله نقشه د ماوس، لمس او کیبورډ په وسیله کار کوي. هر ولایت د فوکوس وړ تڼۍ ده چې ژباړلی نوم او د ټاکنې حالت (`aria-pressed`) لري. په رنګیزه نقشه کې ارزښت یا «معلومات نشته» هم د لاسرسي په نوم کې شامل وي.

| کیلي              | کار                                            |
| ----------------- | ---------------------------------------------- |
| `Tab`             | نقشې ته ننوتل                                  |
| د غشي کیلي        | د ولایتونو ترمنځ جغرافیایي ګرځېدل              |
| `Home` / `End`    | په معیاري ترتیب کې لومړي / وروستي ولایت ته تلل |
| `Enter` / `Space` | ټاکل یا ټاکنه لغوه کول                         |
| `Shift+Tab`       | له نقشې وتل                                    |

په پښتو او دري کې څرګندونې، رنګیز لارښود او ژوندي اعلانونه ښي-نه-چپ دي؛ د غشي کیلي بیا هم د **اصلي جغرافیې** له مخې کار کوي. څرګندونې د لاسرسي د نوم ځای نه نیسي. رنګ د ټاکنې یوازینۍ نښه نه ده: ټاکلی ولایت بېله کرښه لري. د حرکت کمولو تنظیم هم مراعاتېږي.

له خپرولو مخکې په دواړو ژبو په موبایل او کمپیوټر کې د سکرین لوستونکي او کیبورډ ازموینه وکړئ. [بشپړ انګلیسي معلومات](../accessibility.md).
