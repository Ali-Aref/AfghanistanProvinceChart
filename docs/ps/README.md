# د افغانستان د ولایتونو د چارټونو لارښود

دا کتابتون د افغانستان د ټولو ۳۴ ولایتونو لپاره متقابلې او رنګیزې React نقشې برابروي. د ولایتونو پېژندنې معیاري ISO 3166-2 کوډونه دي؛ د نقشې ښودلو لپاره انلاین خدمت ته اړتیا نشته.

- [پیل کول](./getting-started.md) — نصب، لومړنۍ نقشه او بېلګه‌ییز معلومات.
- [ژبنیز ملاتړ](./localization.md) — دري، پښتو، ښي-نه-چپ متن او شمېرې.
- [لاسرسی](./accessibility.md) — کیبورډ او سکرین لوستونکی.
- [د API لارښود](./api-reference.md) — کامپوننټونه او اصلي ځانګړنې.
- [ژوندۍ پښتو بېلګه](../../apps/playground/ps/index.html) — په زېرمتون کې د وېبپاڼې د ننوت فایل.

د [انګلیسي لاسوندونو](../README.md) بشپړه ټولګه، [د معلوماتو سرچینه او جوازونه](../data-and-licensing.md) او [د ګډون لارښود](../contributing.md) هم وګورئ. د کره قانوني متن لپاره [د معلوماتو جواز](../../DATA_LICENSE.md) وګورئ؛ تشریحي ژباړه یې ځای نه نیسي.
