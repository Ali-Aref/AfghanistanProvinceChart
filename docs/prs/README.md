# راهنمای نمودارهای ولایت‌های افغانستان

این کتابخانه برای هر ۳۴ ولایت افغانستان نقشه‌های تعاملی و نقشه‌های رنگی React فراهم می‌کند. شناسه‌های ولایت‌ها کدهای استاندارد ISO 3166-2 هستند؛ نقشه برای نمایش به خدمات آنلاین نیاز ندارد.

- [شروع کار](./getting-started.md) — نصب، نخستین نقشه و دادهٔ نمونه.
- [بومی‌سازی](./localization.md) — زبان دری و پشتو، راست‌به‌چپ و اعداد.
- [دسترس‌پذیری](./accessibility.md) — صفحه‌کلید و صفحه‌خوان.
- [راهنمای API](./api-reference.md) — کامپوننت‌ها و ویژگی‌های اصلی.
- [نمایش زنده به دری](../../apps/playground/prs/index.html) — فایل ورودی وب‌سایت در مخزن.

نسخهٔ انگلیسی [تمام راهنماها](../README.md)، [منبع داده و مجوزها](../data-and-licensing.md) و [مشارکت](../contributing.md) را نیز در بر دارد. برای متن حقوقیِ معتبر به [مجوز داده‌ها](../../DATA_LICENSE.md) مراجعه کنید؛ ترجمهٔ توضیحی جایگزین آن نیست.
