# بومی‌سازی

| مقدار `locale` | زبان                  | جهت        | قالب‌بندی `Intl` |
| -------------- | --------------------- | ---------- | ---------------- |
| `en`           | انگلیسی               | چپ‌به‌راست | `en-US`          |
| `prs`          | دری (فارسی افغانستان) | راست‌به‌چپ | `fa-AF`          |
| `ps`           | پشتو                  | راست‌به‌چپ | `ps-AF`          |

`prs` کد زبان دری در API بسته است؛ آن را بی‌اجازه به `fa` یا فارسی ایران (`fa-IR`) تبدیل نکنید. زبان پیش‌فرض انگلیسی است. نام تمام ۳۴ ولایت، متن راهنماک، راهنمای رنگ، برچسب‌های دسترس‌پذیر و اعداد هنگام تغییر `locale` عوض می‌شوند.

```tsx
<AfghanistanMap locale="prs" />
<AfghanistanChoropleth locale="ps" data={data} showLegend />
```

شناسه‌های ISO مانند `AF-KAB` در هر زبان یکسان‌اند. راست‌به‌چپ تنها به متن و راهنمای رنگ مربوط می‌شود؛ **هندسهٔ نقشه و جهت حرکت جغرافیایی تغییر نمی‌کنند**. عنوان دلخواه `legendTitle` و محتوای دلخواه `renderTooltip` را خود مصرف‌کننده باید ترجمه کند. اگر متن کل صفحه ترجمه شود، `lang` و `dir` سند را هم تنظیم کنید.

نام‌های دری و پشتو با فهرست‌های ولایت‌ها در ویکی‌پدیای فارسی و پشتو مقایسه شده‌اند (بازیابی ۲۰۲۶-۱۱-۲۳). املاهای محلی متفاوت‌اند؛ برای اصلاح نام، منبع معتبر ارائه کنید. [راهنمای کامل انگلیسی](../localization.md) را نیز ببینید.
