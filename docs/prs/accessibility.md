# دسترس‌پذیری

نقشهٔ تعاملی با ماوس، لمس و صفحه‌کلید کار می‌کند. هر ولایت یک دکمهٔ قابل فوکوس با نام بومی‌سازی‌شده و وضعیت انتخاب (`aria-pressed`) است. در نقشهٔ رنگی، مقدار یا متن «بدون معلومات» نیز در نام دسترس‌پذیر می‌آید.

| کلید              | عملکرد                                          |
| ----------------- | ----------------------------------------------- |
| `Tab`             | رفتن به نقشه                                    |
| کلیدهای جهت‌دار   | جابجایی مکانی بین ولایت‌ها                      |
| `Home` / `End`    | رفتن به نخستین / آخرین ولایت در ترتیب استاندارد |
| `Enter` / `Space` | انتخاب یا لغو انتخاب                            |
| `Shift+Tab`       | خروج از نقشه                                    |

در دری و پشتو، متن راهنماک، راهنمای رنگ و اعلان زنده راست‌به‌چپ است؛ کلیدهای جهت‌دار همچنان بر اساس **جغرافیای واقعی** عمل می‌کنند. راهنماک جایگزین نام دسترس‌پذیر نیست. رنگ تنها نشانهٔ انتخاب نیست: ولایت انتخاب‌شده حاشیهٔ جداگانه دارد. حرکت در تنظیمات کاهش حرکت محدود می‌شود.

پیش از انتشار، در هر دو زبان روی موبایل و دسکتاپ با صفحه‌خوان و صفحه‌کلید آزمایش کنید. [جزئیات کامل انگلیسی](../accessibility.md).
